# Créditos e Agradecimentos

O **RL Forge** foi desenvolvido por **TheDroid** com amor para a comunidade de modding do Rocket League. 

Embora o motor do aplicativo e a interface tenham sido escritos do zero em Python (sob a Licença GNU GPL v3.0), o ecossistema depende de ferramentas e dados essenciais criados por terceiros.

Gostaríamos de agradecer e dar os devidos créditos aos seguintes criadores e projetos:

### 1. Banco de Dados e AES Keys
- **Criador(a):** ShinyEmii (Toga)
- **Contribuição:** Toda a lista de IDs de itens, pacotes (UPKs) e as chaves de descriptografia AES vêm do excelente banco de dados mantido pela ShinyEmii no repositório `Toga-Files`. Sem esses dados precisos, este software não seria possível.
- **Link:** [https://github.com/ShinyEmii/Toga-Files](https://github.com/ShinyEmii/Toga-Files)

### 2. Motor de Descriptografia e Re-criptografia
- **Criador:** AltimorTASDK e Comunidade
- **Contribuição:** O arquivo `RLUPKTool.exe` embutido nesta ferramenta é utilizado como *backend* seguro para manipular os arquivos binários `.upk` do jogo sem causar corrupção ou *crashes*. O RLUPKTool é distribuído sob a Licença MIT.
- **Link:** [https://github.com/AltimorTASDK/RLUPKTool](https://github.com/AltimorTASDK/RLUPKTool)
